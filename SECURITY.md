# Безбедносна политика

## Подржане верзије

Безбедносне исправке добија само последња верзија на грани `main`.

## Пријава рањивости

Молимо **не** отварајте јавне issue-е за безбедносне проблеме.

Користите [приватну пријаву рањивости](https://github.com/RSvlad/Timska-kasa/security/advisories/new) (GitHub Security Advisories). Укључите опис проблема, кораке за репродукцију и могући утицај. Покушаћемо да одговоримо у разумном року.

## Модел безбедности

- Нема бекенд сервера; контрола приступа спроводи се у [`firestore.rules`](firestore.rules) и [`storage.rules`](storage.rules).
- Firebase Web API кључ је јаван по дизајну и није тајна. Не комитујте `.env` фајлове, сервисне налоге нити приватне кључеве.
- Приступ имају само корисници са whitelist-е (`allowedUsers`).
